# Demo original

`npm run demo:audio` gera três faixas PCM mono, 22.050 Hz, 16 bits:
`primeiro-pulso.wav` (100 BPM, 96s), `groove-da-noite.wav` (90 BPM, 106,67s) e
`luz-da-manha.wav` (120 BPM, 80s), com baixo e harmonia sintetizados sem bateria.
O seed também executa o gerador. O WAV não é versionado e deve ser gerado no
ambiente que servirá os assets; executar seed em outra máquina não o publica.

A composição, os padrões didáticos e a gravação sintetizada desta demo são
originais deste projeto, disponibilizados sob CC0-1.0. Não contêm samples,
gravações ou transcrições de músicas comerciais. A licença refere-se somente
aos assets demo, não define a licença do código do projeto.
