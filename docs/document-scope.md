# Escopo solicitado: Drum-tracks.docx

Documento do usuário lido em 18/09/2026. Os itens são requisitos do produto;
nenhuma instrução operacional externa foi executada por estar no documento.

| Requisito | Implementação / dependência |
| --- | --- |
| Tabs para todas as músicas / começar com top 100 | Catálogo extensível; três demos originais. Repertório top 100 requer ranking (território/período) e conteúdo autorizado; não simular 100 músicas comerciais com o mesmo groove. |
| Gêneros | Campo no banco e filtro no catálogo |
| Metrônomo | Web Audio, beats da timeline, primeiro beat distinto, rate e seek |
| Orientações durante a música | Dicas por seção com exibição contextual |
| Comentários | Contas, comentários persistidos, autorização e limite de envio |
| Soundtrack | Backings originais disponíveis |
| Retirar instrumentos | Mixer de stems originais no mesmo AudioContext; não separação automática de um MP3 |
| Letras e tradução | Conteúdo original por seção, idiomas identificados e licença |
| Aulas em vídeo | Microaulas originais legendadas geradas localmente, com exemplos de contagem e groove |
| Partitura | Notação rítmica para bateria a partir dos eventos, com legenda e impressão |
| Assinatura mensal | Integração configurável, sem cobrança real nesta entrega; credenciais/produto/preço e operação de pagamentos são externos |

Ordem: dados e conteúdo → ferramentas musicais → aulas/partitura → contas e
comentários → preparação de assinatura → validação ponta a ponta.

Disponibilizar o software não fornece automaticamente licenças de repertório,
gravações, letras ou vídeos. Conteúdo demo será identificado como original.
